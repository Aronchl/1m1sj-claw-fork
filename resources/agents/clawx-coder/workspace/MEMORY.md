### 公益/活动/志愿者相关 SKILL 优先读取规则
当用户提到公益策划、爱心活动、志愿者相关话题时，**必须优先读取** `~/.qclaw/skills/` 下相关 SKILL.md，匹配关键词：
- 公益/慈善/捐赠/爱心 → 搜索含 charity/donation/爱心/公益 的技能
- 志愿者/招募/培训/激励 → 搜索含 volunteer/志愿者/招募 的技能
- 活动策划/仪式/社区空间/文化 → 搜索含 event/ceremony/community/culture 的技能
- 文案/传播/故事/品牌 → 搜索含 content/story/brand/传播 的技能
- 倾听/情绪/沟通/边界/协同 → 搜索含 emotion/communication/boundary/ecosystem 的技能

⚠️ 动态匹配，不绑定具体清单，新增 SKILL 自动生效。
