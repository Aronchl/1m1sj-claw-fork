# 🌸 爱心板块 — shrimp-love

## 核心定位

**爱心 = 公益 + 人设 + 私域**，三者不可分割：

```
公益活动 → 积累故事素材
故事素材 → 塑造人设形象  
人设形象 → 吸引私域粉丝
私域粉丝 → 支撑公益活动
```

这是一个**正向飞轮**，转起来就是社区的温度引擎。

---

## 三大子模块

### 1️⃣ 社区公益

> 让善意落地，让每一份爱心都有回响

| 能力 | 说明 |
|------|------|
| 活动策划 | 策划→招募→执行→总结→传播 全流程 |
| 志愿者网络 | 招募、分级、培训、激励、留存 |
| 捐赠管理 | 接收、登记、反馈、公示闭环 |
| 项目追踪 | 多项目并行、进度看板、效果评估 |
| 公益补给站 | 物资中转、邻里互助、商家联动 |

**活动类型清单：**

| 类型 | 图标 | 说明 |
|------|------|------|
| 物资捐赠 | 🎁 | 衣物/书籍/日用品捐赠 |
| 志愿服务 | 🤝 | 社区清洁/助老助残/活动协助 |
| 公益教育 | 📚 | 讲座/培训/亲子教育 |
| 环保公益 | 🌱 | 垃圾分类/绿化种植/环保宣传 |
| 助老服务 | 👴 | 关爱老人/健康检查/陪伴聊天 |
| 儿童关爱 | 👶 | 课后托管/兴趣培养/安全保护 |
| 爱心集市 | 🏪 | 创业助农/义卖/便民服务 |
| 邻里微心愿 | 💫 | 微小愿望匹配/邻里互助 |

**公益全流程：**

```
策划(7-14天) → 招募(3-7天) → 执行(当天) → 总结(3-5天) → 传播(持续)
```

### 2️⃣ 人设塑造

> 主理人不是岗位，是社区的"人"

| 能力 | 说明 |
|------|------|
| 人设定位 | 确定"社区龙虾"的核心人设标签 |
| 朋友圈运营 | 日常分享/活动预告/感悟/互动 |
| 公众号内容 | 人物故事/活动报道/社区观点 |
| 短视频脚本 | 公益记录/日常vlog/知识科普 |
| 视觉规范 | 配色/字体/emoji风格统一 |

**人设四要素：**

| 要素 | 定义 | 虾管家版本 |
|------|------|-----------|
| 身份 | 你是谁 | 社区龙虾主理人 🦞 |
| 性格 | 你说话的方式 | 温暖如邻居，专业如秘书 |
| 故事 | 你做过什么 | 每次公益都是素材 |
| 价值观 | 你信什么 | 让善意落地 |

**内容日历模板：**

| 星期 | 内容类型 | 频率 | 人设强化点 |
|------|---------|------|-----------|
| 周一 | 公益预告/活动回顾 | 每周 | 行动力 |
| 周三 | 居民故事/暖心瞬间 | 每周 | 共情力 |
| 周五 | 社区观点/生活感悟 | 每周 | 思想力 |
| 周末 | 活动/互动/轻松 | 灵活 | 亲和力 |

### 3️⃣ 私域维护

> 不在微信群里的社区，不是真社区

| 能力 | 说明 |
|------|------|
| 社群搭建 | 建群→拉人→立规矩→养氛围 |
| 日常运营 | 早安问候/午间互动/晚间总结 |

| 粉丝互动 | 回复/点赞/私聊/关怀 |

**社群运营节奏：**

```
早安(8:00) → 午间互动(12:00) → 晚间总结(20:00) → 活动日(全天)
```

**微信群管理关键动作：**

| 动作 | 频率 | 目的 |
|------|------|------|

| 线下活动邀约 | 每月 | 线上线下联动 |

## 关键原则

1. **真诚第一** — 公益不是表演，是真心实意
2. **故事驱动** — 每个活动都是一个故事，故事塑造人设
3. **闭环反馈** — 每一份善意都要被感谢和记录
4. **私域沉淀** — 公益活动不是终点，是把人沉淀到私域的入口
5. **人设一致** — 所有输出保持"温暖+专业"统一调性
