# 🤝 帮扶板块 — shrimp-empower

## 核心定位

**帮扶 = 资源整合 + 数字赋能**，让社区从"乱"到"治"：

```
散落的资源 → 盘点整合 → 匹配需求 → 高效运转
传统的流程 → 数字化改造 → 降本增效 → 居民满意
```

帮扶是社区的**基础设施层**，没有它，爱心飘在空中，成就落不了地。

---

## 三大子模块

### 1️⃣ 社区资源整合

> 资源不在多，在用起来

| 能力 | 说明 |
|------|------|
| 资源盘点 | 场地/人力/商家/政策/设施 全景地图 |
| 需求响应 | 接收→分类→处理→反馈 闭环 |
| 工单管理 | 登记→派单→跟踪→结单 全流程 |
| 多方协调 | 居民/物业/街道办/商家 协同 |
| 供需匹配 | 谁有什么 × 谁需要什么 → 对接 |

**资源分类体系：**

| 资源类型 | 说明 | 典型资源 |
|---------|------|---------|
| 🏢 场地资源 | 活动空间/办公/仓储 | 社区活动中心/共享办公/广场 |
| 👥 人力资源 | 志愿者/专家/服务商 | 社区达人/维修师傅/律师 |
| 🏪 商家资源 | 周边商户/供应链 | 便利店/餐饮/家政/快递 |
| 📋 政策资源 | 补贴/资质/扶持 | 创业补贴/税收优惠/场地优惠 |
| 🔧 设施资源 | 公共设施/设备 | 健身器材/充电桩/快递柜 |
| 💡 信息资源 | 知识/数据/渠道 | 社区档案/行业报告/媒体渠道 |

**需求响应分级：**

| 级别 | 图标 | 响应时效 | 示例 |
|------|------|---------|------|
| 紧急 | 🔴 | 2小时内 | 漏水/停电/安全隐患 |
| 重要 | 🟠 | 24小时内 | 噪音投诉/设施损坏 |
| 一般 | 🟡 | 3天内 | 政策咨询/服务建议 |
| 长期 | 🟢 | 记录跟进 | 停车位/绿化改造 |

**供需匹配流程：**

```
需求收集 → 资源检索 → 匹配推荐 → 双方确认 → 执行跟踪 → 效果评价
```

### 2️⃣ 码世界资源赋能

> 用数字工具把线下社区搬到线上

| 能力 | 说明 |
|------|------|
| 数字化诊断 | 识别社区服务中的数字化机会 |
| 工具推荐 | 码世界/小程序/表单/看板 适配 |
| 流程线上化 | 报名→签到→反馈→统计 自动化 |
| 数据看板 | 关键指标可视化、趋势预警 |
| 一码通方案 | 一码整合社区服务入口 |

**数字化赋能矩阵：**

| 场景 | 线下痛点 | 数字化方案 | 推荐工具 |
|------|---------|-----------|---------|
| 活动报名 | 微信群里接龙乱 | 在线报名表+自动统计 | 腾讯文档/码世界 |
| 志愿者管理 | Excel手动记 | 志愿者库+自动积分 | 码世界小程序 |
| 捐赠记录 | 纸笔记录不透明 | 电子台账+自动公示 | 在线表格 |
| 居民需求 | 口头传达易遗漏 | 工单系统+自动派单 | 码世界/飞书 |
| 数据统计 | 月底手工汇总 | 实时看板+自动报告 | 数据看板 |
| 通知触达 | 群消息被淹没 | 模板消息+已读确认 | 码世界推送 |

**码世界接入流程：**

```
1. 需求诊断 → 确定数字化场景优先级
2. 方案设计 → 选型+流程设计+数据结构
3. 落地实施 → 配置+测试+培训
4. 运营优化 → 数据监控+持续迭代
```

| 能力 | 说明 |

## 关键原则

1. **效率第一** — 把事情办得又快又好
2. **闭环思维** — 每个需求都有始有终
3. **数字优先** — 能线上化的不线下做
4. **数据说话** — 用指标衡量，不拍脑袋
5. **服务至上** — 居民满意是最高标准
