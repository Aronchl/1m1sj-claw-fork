# 🚀 成就板块 — shrimp-achieve

## 核心定位

**成就 = 产品售卖 + 社区赚钱**，让社区有自我造血能力：

```
社区需求 → 产品验证 → MVP上线 → 售卖赚钱 → 规模复制
社区资源 → 生意模式 → 运营优化 → 盈利增长 → 持续造血
```

成就不是孵化完就结束，是**把产品卖出去、把钱赚回来**。

---

## 三大子模块

### 1️⃣ 产业分身产品售卖

> 你有社区经验，这就是可售卖的产品

| 能力 | 说明 |
|------|------|
| 产品化 | 把社区运营经验打包成可售卖产品 |
| 分身模式 | 社区主理人→产品→复制到多个社区 |
| 定价策略 | 价值定价/分层定价/套餐设计 |
| 销售渠道 | 线上商城/社区直销/代理分销 |
| 客户运营 | 获客→转化→交付→续费→转介绍 |

**社区分身产品矩阵：**

| 产品类型 | 说明 | 定价区间 | 典型产品 |
|---------|------|---------|---------|
| 🦞 社区运营SaaS | 社区管理工具包 | ¥299-999/月 | 码世界社区版 |
| 📚 培训课程 | 社区主理人培训 | ¥99-999/课 | 主理人认证课 |
| 📋 咨询服务 | 社区运营咨询 | ¥500-5000/次 | 诊断/规划/陪跑 |
| 🎁 实体产品 | 社区周边/联名 | ¥9-99/件 | 社区IP周边 |
| 💻 数字产品 | 模板/工具/报告 | ¥9-99/份 | 活动模板包/数据报告 |
| 🏪 社区电商 | 团购/分销/代卖 | 佣金5-20% | 社区团购/优选 |

**产品化流程：**

```
经验沉淀 → 梳理标准化 → 打包成产品 → 定价测试 → 上架售卖 → 迭代优化
```

**售卖飞轮：**

```
好产品 → 第一批客户 → 客户口碑 → 更多客户 → 收入投入 → 更好产品
```

### 2️⃣ 社区生意赚钱

> 社区本身就是最好的生意场景

| 能力 | 说明 |
|------|------|
| 生意发现 | 识别社区中的商业机会 |
| 模式设计 | 设计可持续的盈利模式 |
| 增收方案 | 便利店/物业/服务的增收路径 |
| 社区电商 | 团购/分销/自有品牌 |
| 运营优化 | 降低成本/提升复购/增加客单 |

**社区生意类型：**

| 生意类型 | 投入 | 回报周期 | 月收入预期 | 难度 |
|---------|------|---------|-----------|------|
| 社区团购 | 低 | 1-2月 | ¥3,000-10,000 | ⭐⭐ |
| 便利店增值服务 | 中 | 2-3月 | ¥5,000-20,000 | ⭐⭐⭐ |
| 社区培训/活动 | 低 | 1月 | ¥2,000-8,000 | ⭐⭐ |
| 社区广告位 | 低 | 即时 | ¥1,000-5,000 | ⭐ |
| 家政/维修对接 | 低 | 1月 | ¥3,000-15,000 | ⭐⭐ |
| 社区自有品牌 | 高 | 3-6月 | ¥10,000-50,000 | ⭐⭐⭐⭐ |
| 社区SaaS工具 | 高 | 6-12月 | ¥20,000-100,000 | ⭐⭐⭐⭐⭐ |

**增收方法论（便利店场景）：**

```
1. 空间增值 → 社区服务站/快递代收/打印复印
2. 流量增值 → 社群带货/广告位/异业联盟  
3. 服务增值 → 家政对接/票务代售/社区团购
4. 数据增值 → 居民画像/消费分析/精准推荐
```

**盈利模型验证：**

```
收入 = 用户数 × 付费率 × 客单价 × 复购率
成本 = 固定成本 + 变动成本
利润 = 收入 - 成本
盈亏平衡 = 固定成本 / (客单价 - 变动成本)
```

### 3️⃣ 项目孵化与投融资

> 陪跑到成功，不是孵化完就结束

| 能力 | 说明 |
|------|------|
| 项目评估 | 可行性分析+风险评估+决策建议 |
| OKR管理 | 目标设定+里程碑拆解+进度追踪 |
| BP/PPT | 商业计划书+路演PPT+财务预测 |
| 融资对接 | 投资人匹配+融资准备+投后管理 |
| 市场调研 | 竞品分析+行业趋势+用户洞察 |

**项目评估框架：**

| 维度 | 权重 | 评估项 |
|------|------|--------|
| 市场 | 30% | 规模/竞争/需求真实性 |
| 技术 | 25% | 难度/MVP可行度 |
| 经济 | 25% | 启动成本/盈利模式/回本周期 |
| 团队 | 20% | 能力/投入度/互补性 |

**孵化阶段：**

```
入驻期(1月) → 验证期(3月) → 成长期(6月) → 毕业期(2月)
```

**入场判断（满足3条以上）：**

- [ ] 有明确可落地的项目想法
- [ ] 有愿意带头做的核心成员
- [ ] 有初步市场验证（10人需求访谈）
- [ ] 有启动资源（资金或场地）
- [ ] 帮扶基础已稳固（居民满意度高）

**毕业/退出标准：**

| 毕业（满足3条） | 退出（满足2条） |
|----------------|----------------|
| 连续3月收入稳定 | 连续3月无增长 |
| 用户数达标 | 核心团队退出 |
| 团队独立运营 | 无法验证需求 |
| 清晰下一步规划 | 资金链断裂 |

## 关键原则

1. **验证先行** — 找到第一个付费客户，才是真验证
2. **小步快跑** — MVP先上，完美后补
3. **数据驱动** — 用指标决策，不拍脑袋
4. **长期陪跑** — 从想法到盈利全程跟进
5. **敢说真话** — 有风险就直说，不画大饼
